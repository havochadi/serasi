School logos are bundled locally for the Shortest path course cards. `sources.json` records the original image and source page for each institution. Logos were retrieved on 31 October 2026 and remain the property of their respective institutions.

The images retain their original artwork and colours. The SIT image includes white space that is cropped by CSS inside its display frame; the logo itself remains visible at its original proportions. School names remain visible if an image fails to load.

When updating a logo, replace its local asset, update `sources.json` and `SerasiLocal.SCHOOL_LOGOS`, and check the course cards on desktop and mobile. GitHub Pages copies this directory via `.github/workflows/pages.yml`.
