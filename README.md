# Serasi

A career-fit demo for Malay youths aged 18–25 in Singapore. Take a five-part quiz, explore the top 10 role matches and stretch roles, and open job searches or career-coaching resources.

Public site: https://havochadi.github.io/serasi/

## Files

- `index.html`: GitHub Pages entry point.
- `Serasi app.html`: editable app source. Keep `index.html` in sync when changing it.
- `Serasi overview.pdf`: detailed proposal and limitations.
- `Serasi pitch deck.pdf`: presentation.

Open `index.html` in a browser to preview. No build step is required. The Pages workflow publishes only the two HTML files and two PDFs when `main` changes.

## Demo scope

Quiz answers are saved in this browser's local storage and can be removed from the results page. AI chat, shared results, partner insights and job-taster registration rely on Claude services and are unavailable on GitHub Pages. Job links open external searches; they are not vacancy feeds.

The proposed pilot covers 300 youths with a draft S$22,000 budget. Partners and funding are proposed, and scores and the hand-coded role data require validation. See the PDFs for the full plan.
